# Folder 3 - Certificates

This folder contains certificates earned through **Coursera online courses** related to **Python programming, Selenium automation and test automation frameworks**.

The certificates demonstrate learning and training in automation concepts, Python-based testing, Selenium WebDriver, Playwright, and Robot Framework.

## 📜 Certificate Details

The `certificates.md` file contains the course-wise certificate information, including:

* Course name
* Instructor or course provider
* Certificate link

## 📚 Covered Topics

* Introduction to Python and Basic Selenium Setup
* Introduction to Selenium
* Python for Automation
* Selenium WebDriver with Python
* Test Automation with Playwright (Python) & Robot Framework

For complete details and certificate links, please refer to **[certificates.md](certificates.md)**.
