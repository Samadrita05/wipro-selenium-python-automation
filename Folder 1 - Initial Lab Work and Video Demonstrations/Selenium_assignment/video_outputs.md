## 2. 🎥 [Click Here to Watch the Project Assignments Demonstration Video](https://drive.google.com/file/d/1ErfcsWGK1TsGq2MWEoRiZy3z-4wuI80N/view?usp=sharing)
The video demonstrates the execution of four core Selenium Webdriver automation assignments, showcasing the practical application of element location and manipulation:

* **Assignment 1: Web Element Identification** -> Locating unique single web elements using standard locators like `By.ID`, `By.NAME`, `By.TAG_NAME`, `By.LINK_TEXT` and `By.CLASS_NAME` (e.g., username field, password field, and textual links).
* **Assignment 2: Multiple Element Identification** -> Finding and working with collections of elements of the same type, including extracting and printing structural data such as text from all links on a webpage.
* **Assignment 3: CSS Selector Challenge** -> Targeting advanced and dynamic elements using specialized CSS Selectors, featuring wildcard attributes for elements with shifting IDs (e.g., matching prefixes like `user_`).
* **Assignment 4: Child Nodes Using CSS** -> Navigating DOM hierarchies to pinpoint nested child elements using direct parent-child relationships (e.g., selecting a button isolated inside a specific `div`).
