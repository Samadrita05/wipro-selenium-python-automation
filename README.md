## 📁 Folder 2 - Capstone Project

This folder contains the complete Selenium Python Automation Capstone Project.

The actual project is maintained inside:

**Wipro_Selenium_Capstone_project**

The Capstone project demonstrates the development of a structured Selenium automation framework using:
* Python
* Selenium WebDriver
* PyTest
* Unittest
* Page Object Model (POM)
* Utility classes
* Configuration management
* CSV-based test data
* Screenshot handling
* HTML test reporting

### Capstone Project Components

The project is organized into separate framework components:

| Component | Purpose |
| :--- | :--- |
| config/ | Configuration files used by the framework |
| pages/ | Page Object Model classes |
| tests/ | Automated test cases |
| utilities/ | Reusable framework utility classes |
| data/ | Test data files and example test data |
| screenshots/ | Failure screenshots |
| reports/ | Generated HTML test reports |
| conftest.py | PyTest fixture configuration |
| pytest.ini | PyTest configuration |
| requirements.txt | Project dependencies |
| README.md | Complete Capstone project documentation |
| video_demonstration.md | Capstone demonstration video information |

### Automated Scenarios

The Capstone framework automates the following major scenarios:
* Login Automation
* Product Search Automation

The project also demonstrates framework-level features such as reusable page classes, test data handling, configuration management, failure screenshot capture, and HTML reporting.

📌 For the complete technical documentation, framework explanation, execution details, screenshots, reports, and demonstration information, please refer to the README.md inside Wipro_Selenium_Capstone_project.
